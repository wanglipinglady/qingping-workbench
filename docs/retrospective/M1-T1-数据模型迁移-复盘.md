## 6. 经验沉淀

1. **云数据库访问**：云服务器 MySQL 通常限制公网 IP 访问，开发时最好先用本地 SQLite，生产环境在服务器本机执行初始化
2. **模型先行**：先定义 SQLAlchemy 模型，用 SQLite 快速验证，再到 MySQL 上执行，避免来回调试网络问题
3. **密码转义**：DATABASE_URL 中密码的特殊字符（如 `@`）需要 URL 编码为 `%40`，否则连接失败
4. **版本管理**：每次任务完成后立即 git commit + 更新 CHANGELOG，避免后续忘记改了什么
