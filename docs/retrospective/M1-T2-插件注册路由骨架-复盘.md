## 3. 遇到的问题与根因

|---|---|---|
| 登录接口 422 错误 | 误用 `data=` 传 form data，接口需要 JSON body | 改用 `json=` 传参 |

## 6. 经验沉淀

1. **登录参数格式**：FastAPI 接口用 Pydantic Model 接收的是 JSON，用 `json=` 传参；用 Form 接收的是表单，用 `data=` 传参
2. **TestClient 局限性**：TestClient 不会触发 `on_event("startup")`，需要手动执行初始化逻辑
3. **插件发现机制**：只要在 `app/plugins/` 下创建目录并包含 `plugin.py`（定义 `register` 函数），插件就会被自动发现，无需额外配置
4. **Schema 先行**：先定义好请求/响应的 Schema，后续写业务逻辑和前端对接时会非常顺畅，减少返工
